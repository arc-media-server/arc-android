# A README for people, not just builders

The README was all build instructions. It now introduces the app the way the server's and the
Kodi add-on's READMEs do: the stacked Arc logo, a one-line summary, badges, a large Home
screenshot, an alpha note, a grid of screens, "What it does" by area, how to install it on a TV
and sign in, then the developer sections (build, SDK set-up, GitHub builds and signing, the live
server test, layout) and the licence.

The screenshots in `docs/screenshots/` are JPEGs of the Roborazzi renders (made-up titles and
generated artwork, no real films), re-rendered from main on 16 November. The logos in
`docs/brand/` are copies of the server's. Every feature listed was checked against the code;
Watch Together isn't listed because the app doesn't have it yet.
