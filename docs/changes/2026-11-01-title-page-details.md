# Title pages: episode cards and the whole description (1 November)

To match the Apple TV app's title pages more closely (owner, 1 November; the TV web app,
arc-tv#2, has the same change):

- **Episode cards** are a little wider (200dp) and show, under the still, a small "EPISODE 3"
  line, the name, three lines of the description (always, not only when focused) and the length,
  or the time left when it's part-watched.
- **Description:** beside the buttons it still shows three lines. When that cuts it short, MORE
  shows under it and the description can take the focus (Right from the last button); OK opens
  the whole text in a floating panel, and Back or OK closes it, returning to the description.
- Cast was already round photos with the character underneath, as Apple's.

New screenshot test: `tv-movie-about`.

Logging: none added; layout only, with no new loads.
