# The new Arc logos in the app

The app still drew the old teal "arc over a dot" mark, from before the owner chose the new logo
set on 13 November (the server's `docs/brand`). It now uses the new one, white, with no colour:

- `arc_logo` is the main logo (the TV with "arc" and "MEDIA SERVER"), at the top of the server
  and sign-in screens and on the profile picker.
- `arc_logo_stacked` (new) is the TV above the name, for the launch screen and Settings → About,
  as the brand guide asks for TV apps' sign-in and splash screens.
- `arc_mark` is the TV alone. The launcher icon is built from it, so the icon is now the white TV
  on the app's near-black background, as `arc-icon.svg`.
- The Android TV banner (`tv_banner.png`, shown in the TV's apps row) is redrawn with the main
  logo, white on near-black.

The drawables are converted directly from the server's SVGs (the lettering is drawn as shapes, so
no font is needed); each says which file it came from.

Checks: `./gradlew assembleDebug testDebugUnitTest recordRoborazziDebug` passed. The sign-in,
server, profile picker and About screenshots were checked. No logging changes.
